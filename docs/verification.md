## 페이지 로딩 개선 — 2026-10-28

목록과 이미지 요청마다 전체 데이터셋 JSON 약 19MB를 반복 해석하던 경로를 SQLite 파생 요약·이미지 인덱스로 변경했습니다. 화면별 필요한 목록만 조회하고, 작업 결과와 학습 이력은 선택한 작업의 상세 API에서 가져옵니다. 목록 자동 갱신은 실행 상태 화면 4초, 일반 목록 30초이며 숨겨진 탭은 쉬고 돌아올 때 갱신합니다.

실제 공개 주소 `http://121.126.210.3:18091`에서 같은 서버·브라우저 조건으로 측정했습니다.

- Python 26개 테스트 통과: 기존 기능과 함께 인덱스 초기화·외부 연결의 쓰기·롤백·삭제·목록/이미지 조회·기존 전체 API 호환성을 확인했습니다.
