## 모델 API 영역 구분, 전체 평가, 모델 선택 목록 — 2026-10-29

- 모델 API는 상단 등록 목록과 하단 `선택한 API` 영역을 구분했습니다. 선택한 이름·모델·신규 요청 접수 상태 아래에 연결 정보, 요청 테스트와 이력을 묶고, 요청 결과는 독립 영역에 표시합니다. 선택 표시와 신규 접수 상태를 분리했습니다.
- 모델 API의 상품 카테고리 입력과 기본 호출 예제의 카테고리 쿼리를 제거했습니다. 카테고리 없이 접수한 이미지는 기존 자동 분류 프롬프트와 카테고리별 검증을 사용합니다. 판별 결과는 `result.category`와 `category_valid`에 반환하며 판별 불가·누락은 모든 속성을 판정에서 제외합니다. 기존 카테고리 지정 클라이언트와 과거 요청 조회는 유지합니다.
- 평가 화면의 최대 샘플 수 입력을 제거했습니다. 기본값은 테스트셋 전체이며 검증셋 선택 시에도 전체를 평가합니다. 기본 API 요청의 `sample_limit`는 null이고 기존 명시적 제한은 호환성을 위해 유지합니다. 워커와 추론 진행 건수도 전체 개수를 반영합니다.
